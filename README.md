末日肉鴿生存遊戲功能介紹

遊戲概念

這是一款肉鴿類射擊生存遊戲。玩家將在末日廢墟中求生，透過擊敗敵人獲取獎勵來不斷強化自身。每次挑戰都會遭遇隨機的敵人與還有3種BOSS，抵達測離點回到地堡或是死亡。

********************
遊戲流程

1. 地堡基地

地堡是遊戲的安全區域有以下功能：

開始突襲：進入戰鬥地圖。

黑市購買：花費廢料進行永久屬性升級。

收藏箱：管理與存放物品。

改造台：強化或調整武器屬性。

武器庫：裝備或切換武器。

2. 開始突襲

進入大地圖後戰鬥正式開始。敵人會持續湧現，玩家需要擊敗敵人拾取廢料、經驗與物資，同時提升角色能力，並在最後尋找撤離點逃脫。

4. 超時事件

若存活時間超過限制，將觸發BOSS軍隊事件。大量精英敵人會隨之出現，遊戲難度大幅提升。

5. 結束或繼續

成功：抵達撤離點並完成進度條，安全返回地堡。

失敗：血量歸零，遊戲結束，失去當前局的進度。

********************
武器系統

武器包含傷害、射速與子彈類型等屬性。

稀有度由低至高分為白色、藍色、紫色與金色，分別對應0至3個隨機屬性。

可獲得的武器屬性：

速射：提升射擊速度。

散射：發射更多子彈。

吸血：擊中敵人恢復生命。

爆擊：提升造成三倍傷害的機率。

穿透：子彈可穿過敵人。

燃燒：造成持續性傷害。

武器類型：

手槍：能力平衡，適合全場。

散彈槍：扇形攻擊，適合近距離群傷。

狙擊槍：高傷害且具備穿透能力。

激光：射速快，且能追蹤敵人。

機槍：連射火力，持續輸出。

火焰槍：造成短距範圍傷害與燃燒效果。

大炮：拋物線投射，具備大範圍爆破效果。

冰霜槍：減緩敵人移動速度。

子彈運算

基礎子彈以直線運動，每幀位置計算公式為：新位置 = 舊位置 + 方向向量 × 速度。導引子彈則會根據與敵人的夾角進行平滑轉向。

********************
角色系統

角色具備血量、盾牌、體力與能量四種基礎屬性。

衝刺

消耗體力進行高速閃避。

戰鬥

透過擊殺敵人獲取經驗球，升級後可從三張強化卡片中選擇一項。

無敵機制

受擊後會短暫進入無敵狀態，防止連續扣血。

背包與物品

背包分為隨身攜帶與地堡存放空間。物品包括用於回復生命的醫療包、貨幣廢料以及武器。玩家可使用拖放功能整理空間，或按X鍵出售多餘物品。

********************
改造台與升級

改造台

位於地堡中央，用於提升武器稀有度（需消耗廢料），或重新隨機抽取武器屬性。

********************
升級強化

升級時提供的卡片分為三類：

攻擊類：增加射速、傷害或子彈數。

支援類：優化體力恢復、提升移動能力。

生命類：提升盾牌上限、血量或增加自動回血功能。

********************
敵人與BOSS

敵人

包含近戰、遠程與自爆三種基本類型。敵人強度會隨玩家等級與難度模式（普通或挑戰）動態調整。

BOSS

共有三種，分別具備不同特性：

黃色BOSS：基礎射擊型。

衝刺突擊者：高機動性，具備硬直空窗期。

紅色BOSS：多階段戰鬥，攻擊模式會隨血量降低而改變。

********************
難度機制

普通模式：敵人基礎強度，無彈藥限制，適合新手。

挑戰模式：敵人強度大幅提升，增加換彈冷卻機制（R鍵換彈），BOSS出現更早，但獎勵更加豐厚。

講稿

遊戲視窗管理系統運作機制
toggle_fullscreen 函式與自適應解析度縮放機制。 當玩家按下全螢幕快捷鍵時，程式會動態切換 pygame.FULLSCREEN 旗標，同時透過 pygame.display.Info() 取得當前螢幕實際尺寸。關鍵在於內部畫布 screen 始終保持固定的 1024×768 解析度，而實際顯示視窗 real_screen 則根據全螢幕或視窗模式自動縮放。遊戲也根據 SCALE 變數動態計算四種字體大小（font、large_font、small_font、tiny_font），使用 max() 函式確保字體尺寸永遠不會低於最小可讀閾值。當視窗被改變大小時，所有依賴 SCALE 的UI元素會自動調整，使得各種裝置上的遊戲表現保持一致，文字始終可讀。
相機系統與屏幕震動機制、多層繪製順序。 遊戲透過 camera_x 和 camera_y 追蹤玩家視角位置，所有世界座標的物體在繪製時都需減去相機偏移量以實現視角跟隨效果。當Boss受到攻擊或發動大招時，screen_shake 變數會被設定為非零值，系統每幀自動衰減並在繪製時動態偏移，營造出強烈衝擊感。遊戲採用嚴格的繪製優先級制度：先繪製背景，再繪製地圖物件、敵人和子彈，然後是玩家，最後是UI面板（任務欄、Boss血條、迷你地圖）。這個順序確保前景元素永遠出現在背景之上，UI永遠浮在遊戲世界之上不會被遮擋，使複雜場景也能清晰呈現。

圖片、音效、動畫加載系統運作機制
load_image 與 load_animation 函式的資源載入與容錯機制、load_sound 與專屬武器音效備援機制、多通道音效管理。 遊戲透過 os.path.exists() 預先檢查資源檔案是否存在，當檔案存在時，pygame.image.load() 搭配 .convert_alpha() 進行最佳化載入，使用 pygame.transform.scale() 統一縮放至指定尺寸，所有資源都被集中存放在全域字典 images、animations 和 sounds 中。對於不存在的檔案，系統會設定該資源為 None 並自動建立缺失的資料夾，確保遊戲不會中斷。遊戲在初始化時透過 pygame.mixer.set_num_channels(64) 配置64個獨立音效通道，每個音效都統一設定音量，而武器音效則透過 load_weapon_sound() 函式實現智能備援機制：當指定檔案缺失時自動改用通用音效替代，確保遊戲流程不被打斷。背景音樂使用 pygame.mixer.music.play(loops=-1) 實現無限循環，與音效層完全分離，即使激烈戰鬥中音效頻繁重疊也不會中斷背景樂。

任務系統運作機制
戲透過 Task 類別為每個任務維護獨立的進度計數器 current_progress，並透過 check_completion() 方法在每次進度更新時判斷是否達成目標值，自動標記任務完成狀態。TaskSystem 管理著由六種基礎任務組成的任務池，包括「廢料獵人」、「初級獵人」、「精英獵人」、「武裝分子」、「長期作戰」等多樣化目標，系統透過 generate_new_task() 函式從可用任務中隨機選擇（已完成的任務會自動排除），確保遊戲中始終有一個活躍的當前任務。當玩家完成任務時，apply_reward() 方法會根據任務的 reward_type（廢料、經驗、最大血量、傷害加成、最大體力）動態應用獎勵，直接修改玩家或持久化統計數據，使得獎勵系統靈活且易於擴展。遊戲透過 update_progress() 方法在各個事件點（敵人死亡、造成傷害、時間經過）動態調用，只要 objective_type 吻合就會累加進度並檢測完成狀態，返回布林值供主遊戲迴圈判斷是否觸發完成事件。

升級卡牌系統運作機制
遊戲透過 upgrade_options 陣列定義18種升級卡牌，每張卡牌都擁有 title、desc、type（攻擊/支援/生命）和 weight（權重值），其中某些卡牌如「擴容彈匣」和「戰術無人機」被標記為 challenge_only，僅在挑戰模式下出現。choose_upgrade_cards() 函式透過加權隨機演算法從可用卡牌中選擇3張供玩家挑選：系統先根據 game_mode 篩選出符合條件的卡牌，計算所有權重的總和，然後生成隨機數並透過累加權重進行區間判斷，確保高權重卡牌（如「超頻運轉」權重為5）出現頻率高於低權重卡牌（「生命躍升」權重為1）。當玩家選擇卡牌時，apply_upgrade() 方法會根據卡牌名稱直接修改玩家屬性（如「生命躍升」增加50血量、「超頻運轉」降低機槍冷卻、「戰術無人機」增加無人機等級），同時透過 chosen_upgrades 字典追蹤每張卡牌的選擇次數，使得玩家可以在暫停選單中查看已獲得的強化總覽。這種設計使得升級系統既保有隨機性又維持平衡性，高收益卡牌自然出現率更高，但低收益卡牌仍有機會被選中，創造出豐富的遊戲策略空間。

導引和碰撞檢測
戲為玩家子彈維護 guidance_level 參數，當子彈更新時透過 min(all_enemies, key=lambda e: math.sqrt(...)) 自動鎖定最近敵人，使用向量插值逐幀調整方向向目標靠攏，導引速度根據等級動態加快。主遊戲迴圈對每發子彈執行 for e in enemies: 遍歷，透過 b.rect.colliderect(e.rect) 檢查碰撞，一旦觸發則依序扣除敵人護盾、生命，並根據子彈類型應用特效（冰霜減速、燃燒持續傷害、吸血回血）。穿透子彈碰撞後繼續前進，火焰手榴彈碰撞時直接觸發爆炸產生AoE傷害。暴擊子彈會觸發屏幕震動與視覺延遲效果。Boss碰撞則獨立判斷，且只在可受傷狀態才應用傷害。

掉落物品系統
遊戲在敵人死亡或寶箱開啟時生成掉落物品，每個物品都維護與玩家的距離計算 dist_sq = (self.x - p_x)**2 + (self.y - p_y)**2，一旦距離進入磁力範圍 mag_rad（由玩家升級決定），系統自動啟動吸附機制，物品以每幀8-25像素的速度吸向玩家。fast_transfer() 函式在物品被吸入背包時優先嘗試堆疊同類物品，透過檢查物品類型是否相同且未達堆疊上限，自動合併相同物品，若無法堆疊則尋找空格子放入。不同物品類型掉落有不同機率：普通敵人40%掉EXP、15%掉廢料、35%掉經驗、40%掉急救、特殊物品（磁鐵、炸彈）機率均為1%；精英敵人保證掉落經驗、血瓶、護盾及廢料。特殊物品如「遺失物」會在玩家死亡時生成，記錄玩家的等級、經驗、升級次數與完整背包，玩家接觸時可恢復所有數據。撤離點則作為逃脫勝利條件，玩家進入範圍內即觸發成功判定。

武器類型的子彈
 遊戲定義九種子彈類型，每種都擁有獨特的速度、半徑、顏色與特殊效果。普通子彈（手槍）以平衡的速度與傷害提供基礎輸出；穿甲子彈（狙擊槍、機槍、步槍）透過設定 self.is_piercing = True 使其能穿透敵人繼續前進，不會因單一敵人碰撞而消失，速度提升至28像素且傷害更高；散彈槍透過敵人的發射邏輯生成扇形彈幕，玩家散彈則透過 player.bullet_count 在同一射線上發射多發子彈。火焰子彈生命週期短（25幀）且速度慢（12像素），碰撞敵人時設定 e.burn_timer = 180 產生持續燃燒傷害。冰霜子彈碰撞時設定 e.frost_timer = 120 使敵人速度降低60%。雷射子彈速度極快（45像素）且半徑小，強化穿透特性。大炮砲彈速度慢但傷害巨大，碰撞敵人時會產生推力，使敵人遠離玩家30像素。火焰手榴彈則透過距離判斷 if math.sqrt((self.target_x - self.x)...) < self.speed 在靠近目標時自動爆炸，觸發 b.explode = True 產生120像素AoE傷害。等離子子彈則綜合高速與高傷害特性。

敵人生成系統運作機制
遊戲透過全域計時器 enemy_spawn_timer 每幀遞減，當計時器達到0且未在Boss戰期間時，系統自動生成新敵人。敵人上限設定為150個，超過上限則停止生成，確保遊戲效能不被過多敵人拖累。每次生成時，敵人等級自動與玩家等級同步 Enemy(player.level, ...)，使敵人難度隨遊戲進度自動升級。敵人生成間隔透過公式 max(5, 30 - player.level) 動態調整，玩家等級越高生成間隔越短，形成漸進式難度加劇。敵人類型則透過 random.random() < 0.15 判定，15%機率生成菁英敵人，85%生成普通敵人，菁英敵人自動擁有50級別加成、更高屬性與隨機戰鬥類型。Boss戰期間停止普通敵人生成 if not boss_army_active，而超時未撤離時會觸發Boss軍隊出現，敵人屬性進一步倍增（+15級加成、所有屬性x4、速度x1.3），帶來最高難度挑戰。

地堡四大系統運作機制
遊戲中地堡提供四個獨立功能區，玩家透過按E鍵切換。黑市透過固定價格機制消耗50廢料升級屬性（血量+10、傷害+2、速度+0.2、體力+20、護盾+20、能量+20），每次升級直接修改玩家永久屬性並保存至 persistent_stats 字典。收藏箱提供36格通用背包，透過左鍵拖放物品、右鍵快速轉移同類物品至玩家背包，拖放時自動進行堆疊檢測，確保背包空間利用率最大化。改造台允許選擇裝備或背包中的武器，透過「升級」按鈕以50/150/300廢料逐級提升稀有度（白→藍→紫→金），每次升級自動追加隨機屬性（最多3個），透過「重抽」按鈕以30/80/150廢料重新隨機附加屬性組合，滿足玩家的個性化打造需求。武器箱展示所有可用武器，包括基礎武器與武器庫存，玩家可選擇武器並點擊主副武按鈕將其裝備，舊武器自動返回武器庫，系統透過 sort_weapon_stash() 維持武器按稀有度排序。所有系統都透過 persistent_stats 全局字典實現跨session持久化，玩家資源與裝備狀態永遠不會丟失。
